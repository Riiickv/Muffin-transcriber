# Release notes, versionCode 119 (version 2.0)

Paste each block into the matching language in Play Console under
Release > Production > Release notes. Play's limit is 500 characters.

Play currently holds 108, so these cover everything from 109 to 119.
Chat is hidden since 118 (`utils/features.ts`), so it is not mentioned.
Names are copied from `constants/strings.ts` ("Fast, high quality"). The Black
theme and accent colors were already in 108 (only their labels became
translatable), so they are not claimed as new. The storage line says what changed, not that notes were at risk:
the loss needed a library past 2 MB and is described in
`docs/storage-research.md`.

Approved by Ricky ("let's do everything else"), 2026-11-15.

---

## en-US

Hello! A big update this time.

- A new speech model, Fast, high quality: much quicker, for 25 European
languages.
- Transcriptions are now stored one by one, so very large libraries load
reliably.
- Shorter, clearer settings, now fully translated.

Everything still runs on your phone. Nothing is uploaded.

Thank you for using Muffin!
