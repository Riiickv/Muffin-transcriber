# Release notes, versionCode 108

Paste each block into the matching language in Play Console under
Release > Production > Release notes. Play's limit is 500 characters.

Two deliberate choices in here:

1. The last line mentions the speed work from 107, because publishing 108
   REPLACES 107's notes on the listing. Anyone who has not updated yet goes
   straight from the old version to this one and would otherwise never see it.

2. It does not say transcriptions "continue in the background". What was fixed
   is that the screen no longer sleeps partway through and suspends the job.
   Switching to another app still stops it, and promising otherwise invites
   people to do exactly the thing that does not work yet.

Setting names are copied from `constants/translations/`, so the notes name each
switch exactly as the app labels it.

---

## en-US

Hello! Another update for you.

Your transcriptions can now leave the app:

- Export transcriptions saves them all to a folder you choose, as a text file
you can open anywhere.
- Keep transcriptions after uninstalling keeps a copy in that folder, so
removing Muffin no longer erases everything.

Nothing is ever uploaded. You pick the folder and it stays on your phone.

Also from the last update: transcriptions no longer stop halfway, and they are
much faster.

Thank you for using Muffin!
