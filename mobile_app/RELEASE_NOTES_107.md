# Release notes, versionCode 107

Paste each block into the matching language in Play Console under
Release > Production > Release notes. Play's limit is 500 characters per
language; every block below is well inside it.

The model names are copied from `constants/translations/`, so they match what
the app actually shows on screen in each language.

---

## en-US

Transcriptions used to stop halfway and only continue when you woke your phone.
That is fixed.

Also faster:
- Fastest is about 40% quicker
- Most accurate is now the suggested model on newer phones. It turned out to be
  twice as fast as Balanced.

And you can see what is going on: the waiting screen shows how far along it is
and how long is left, and the model list gives honest time estimates.

Thank you for using Muffin!
